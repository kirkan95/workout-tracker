  • 1 Week bar: dots colored by workout type (tokens --push/--pull/--legs/--cardio). Done = filled + ✓; today = volt ring; past missed workout day = hollow red tint. Tapping any day opens a bottom-sheet preview of that day's plan.
  • 2 Session header (sticky while scrolled): SVG progress ring = sets logged / total (stroke-dashoffset), running volume (Σ weight×reps) and elapsed time. Name uses the day-type color.
  • 3 Coach note: engine or AI note, volt left border. Same slot as today's planDay.note.
  • 4 Exercise card: volt "reason" line comes from engine/progression.ts. Swap opens a sheet of alternatives (same movement + muscles, filtered by equipment/exclusions). "?" how-to stays, behind long-press or the swap sheet.
  • 5 Set rows: pre-filled with target. Active row highlighted, steppers ±2.5 lbs / ±1 rep, tap number for keyboard. ✓ logs the shown values and auto-starts the rest timer — happy path is one tap. Feel = three always-visible dots (green/amber/red). Logged rows dim; "▲ beat last" chip when set > previous session's same set.
  • 6 Rest timer bar replaces the floating pill: fixed above bottom nav, drain-fill background, tabular numerals, +15s and skip. Timestamp-based countdown (survives phone lock — UPGRADE.md §1.3).
