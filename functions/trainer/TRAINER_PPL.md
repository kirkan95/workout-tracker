# Trainer — PPL (Push / Pull / Legs)

Included for: **Get Stronger**, **Build Muscle**

## Rep Ranges

- **Get Stronger**: 3–6 reps. Heavy weight, long rest (3–5 min between sets).
- **Build Muscle**: 8–15 reps. Moderate weight, moderate rest (60–90 sec between sets).

## Volume & Mesocycle

- Start each mesocycle near Minimum Effective Volume (MEV). Add 1 set per muscle group per week toward Maximum Adaptive Volume (MAV). Stop before Maximum Recoverable Volume (MRV).
- **Mesocycle**: 4–6 week block. Week 1 = low volume baseline. Each week += 1 set. Final week = deload.
- **Deload**: Drop volume ~40%, keep same weight. Required for recovery and continued progress.
- **Weekly MEV→MAV per muscle group**: Chest 10–20 sets, Back 10–25 sets, Shoulders 8–20 sets, Legs 10–20 sets, Arms 6–14 sets.

## Session Structure

Order exercises within each session:
1. **Primary compound** — heaviest movement, done first while the user is fresh
2. **1–2 secondary compounds** — supporting movements for the same muscle group
3. **1–2 isolation exercises** — single-muscle finishing work
4. **Core** — legs days only, always at the end

## Exercise Rotation

**Get Stronger**
Strength is a skill — motor pattern repetition drives progress. Keep primary lifts fixed for months, not just one mesocycle. Rotate accessories only at mesocycle boundaries, and only 1–2 at a time. Prioritize compound movements; minimize isolation work.

**Build Muscle**
Keep all exercises fixed for the full mesocycle so volume and progressive overload can be tracked week over week. Rotate the full selection at each mesocycle boundary to hit muscles from different angles. Balance compounds with isolation work.
